About PhishGuard

PhishGuard is a machine-learning-based phishing URL detection system designed to identify potentially malicious and legitimate website URLs.

Project Features

  • Real-time URL feature extraction
  • Random Forest classification model
  • Phishing and legitimate URL prediction
  • Scan history using SQLite
  • Analytics dashboard

Datasets

  • PhiUSIIL Phishing URL Dataset
  • PhishStorm URL Dataset

Machine Learning Algorithms

  • Random Forest
  • Decision Tree
  • Logistic Regression
  • Extra Trees

Predictions are based on URL characteristics and should not be treated as a guarantee of website safety.
